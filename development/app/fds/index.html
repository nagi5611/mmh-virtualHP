FDS Experience App

FDS体験アプリ

FDS（Fire Dynamics Simulator）の解析結果を粒子表示で可視化し、 煙・火災環境の中を歩きながら避難を体験できるVR／デスクトップアプリです。

01

アプリの概要

FDS体験アプリ（Fire Simulation VR）は、火災動力学シミュレータ FDS で算出した 煙濃度（SOOT）と発熱量（HRRPUV）の時系列データを前処理し、Unity 上で粒子として描画します。 プレイヤーは建物内を一人称視点で移動し、煙の充満や酸素低下を体感しながら避難ゴールを目指します。

教育・防災訓練向けに、シミュレーション結果を「見る」だけでなく「歩いて感じる」体験へ変換することを目的としています。

02

主な機能

  • FDSデータの可視化 — 前処理済み粒子データをタイムステップごとに再生し、煙と火の広がりを表示
  • 避難体験ゲーム — 指定エリアへ到達するとクリア。生存時間や移動経路を記録
  • 酸素・煙吸入システム — 煙環境にいるほど酸素上限が下がり、息切れ・スプリントで酸素を消費
  • 視界・移動の阻害 — 煙にさらされると視界が狭まり、移動速度や視点が不安定になる
  • 難易度選択 — イージー／ハードで体験の厳しさを切り替え
  • シナリオ選択 — 複数の火災シナリオ（例: prod01）を切り替えて体験可能
  • シナリオデータの利用 — prod01.firesim 〜 prod10.firesim をダウンロードしてアプリ内でシナリオを切り替え
03

データの流れ

  1. FDS で火災シミュレーションを実行（SOOT・HRRPUV などの出力）
  2. Python スクリプトでグリッドデータを粒子データへ変換（fdstoraw.py → rawtoparticles.py）
  3. 解析結果はシミュレーションページで .zip として公開（prod01〜prod10）
  4. 体験アプリ用に .firesim 形式のシナリオデータへ変換し、本ページから配布
  5. アプリが .firesim を読み込み、ゲーム内で時系列再生

シミュレーション本体の詳細は シミュレーション カテゴリーを参照してください。

05

配布・ダウンロード

アプリ本体をダウンロードして体験できます。シナリオデータ（.firesim）は容量が大きいため、別途ダウンロードが必要です。

Windows 版

対象: Windows 10 / 11（64bit）

デスクトップ向けビルド。ZIP を解凍して FireSimulation.exe を実行してください。

ダウンロード（ZIP）

Meta Quest 3S 版

対象: Meta Quest 3 / 3S

APK をヘッドセットへ sideload してインストールします。大容量シナリオは Download/FireSimulation/Simulations/ への配置が必要な場合があります。
